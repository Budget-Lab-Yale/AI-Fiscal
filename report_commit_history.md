# Report commit history

This file maps public reports / outputs that use AI-Fiscal to the
specific model version (git SHA) used to produce them. Modeled on
[Tax-Simulator's equivalent file](https://github.com/Budget-Lab-Yale/Tax-Simulator/blob/main/report_commit_history.md).

When a report ships, add a bullet under the appropriate year with the
report title, link, and a permalink to the model tree at the
producing commit.
